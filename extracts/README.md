# extracts

Curated inputs for one network function. `{nf}` is the prefix (`nrf` is the set in this repo).

| File | What |
|---|---|
| `{nf}-outline.md` | Heading tree from the DOCX |
| `{nf}-keep.txt` | Clause numbers chosen for the slice |
| `{nf}-slice.md` | Those clauses, exported from the DOCX. Shorten this file at the pause. The Analyst reads it |
| `{nf}-scope-clarifications.md` | Scope and clarifications, maintained by hand |
| `{nf}-openapi-extract.yaml` | OpenAPI extract, maintained by hand |

The full specification dumps stay on disk for local work and are gitignored.
